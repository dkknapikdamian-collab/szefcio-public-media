# szefcio-public-media

Publiczne, tymczasowe repo na media do testów automatycznej publikacji.

## Struktura

media/<projectId>/<YYYY>/<MM>/<issue>_<sha12>.<ext>

Przykład:

media/SZEFCIO__fitness_veyra/2026/05/DAM-49_8239d29ce10c.png

## Zasady

- Nie wrzucamy tu nic prywatnego.
- Repo jest publiczne.
- Usuwanie plików po czasie to cleanup, nie gwarancja prywatności.
- Każdy asset musi mieć projectId, issueIdentifier i sha.
- Ten repozytorium służy do publicznego URL dla API sociali.
